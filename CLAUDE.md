# Arkiba Agent Instructions

This repository uses a shared autonomous engineering protocol.

Before doing any work:
1. Read .ai-session/MISSION.md
2. Read .ai-session/PRODUCT.md
3. Read .ai-session/PROTOCOL.md
4. Read .ai-session/SECURITY_MODEL.md
5. Read .ai-session/CURRENT_TASK.json
6. Read the matching task spec under .ai-session/tasks/

Never treat a mock, fake integration, hard-coded demo path or simulator as production completion.

Never place real patient data, production credentials or secrets in prompts, issue comments, PR comments, .ai-session, fixtures or committed screenshots.

Role-specific instructions are in:
- .ai-session/agents/BUILDER.md
- .ai-session/agents/REVIEWER.md
- .ai-session/agents/ASTRA.md
